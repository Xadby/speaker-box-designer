# Speaker Box Designer

Браузерный конструктор акустических корпусов: 3D-модель с реалистичными текстурами, расчёт объёма и частоты настройки, карта раскроя и экспорт чертежей.

## Возможности

- **Типы корпуса**: закрытый ящик, фазоинвертор (круглый порт), щелевой порт, бандпасс 4-го и 6-го порядка.
- **3D-модель** (Three.js r160): корпус собран из 6 панелей с реальными вырезами, объёмные динамики и порты, режим «рентген», размерные линии, защитный гриль.
- **Процедурные текстуры** (генерируются в canvas, без внешних картинок): МДФ, фанера, шпон дуба и ореха, карпет, матовая краска, чёрный лак, белый глянец, карбон. Отдельно задаются отделка корпуса и лицевой панели, материал диффузора (бумага, полипропилен, карбон, алюминий).
- **Расчёты**: внутренние размеры, объём брутто/нетто (с вычетом динамиков, портов, перегородки), частота настройки Fb (Гельмгольц с концевой поправкой), подбор длины порта под заданную частоту, масса корпуса и площадь материала.
- **Проверки**: предупреждения, если динамик/порт не помещается на панели или порт упирается в стенку.
- **Раскрой**: таблица деталей с размерами и количеством отверстий.
- **Экспорт**: JSON (проект), PNG (скриншот), STL (корпус для 3D-печати), DXF (развёртка панелей с отверстиями для ЧПУ), PDF (сводка + раскрой, на русском).
- **Автосохранение** в localStorage; проекты старого формата импортируются автоматически.

## Запуск

Приложение использует ES-модули, поэтому его нужно открывать через HTTP-сервер (не `file://`):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Three.js и jsPDF подгружаются с CDN jsDelivr — нужен интернет.

## Управление

- ЛКМ — вращение, колесо — масштаб, ПКМ / Shift+ЛКМ — сдвиг.
- «Вписать» — вернуть камеру к корпусу.

## Структура

```
index.html        разметка и import map
css/style.css     стили
js/main.js        точка входа, состояние приложения и действия
js/state.js       модель данных, валидация, сохранение и миграция
js/calculator.js  геометрия панелей, объёмы, порты, раскрой
js/scene.js       3D-сцена Three.js
js/textures.js    процедурные текстуры и материалы
js/ui.js          панель управления и вывод результатов
js/export.js      экспорт JSON / PNG / STL / DXF / PDF
```
